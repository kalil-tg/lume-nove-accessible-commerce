# Contra project copy

## Project title

Accessible EU E-commerce Remediation — React + WCAG 2.2

## Short description

I designed, rebuilt, and tested a premium European commerce journey with accessible product selection, modal cart behavior, checkout validation, responsive reflow, and Playwright plus axe regression coverage.

## Portfolio description

LUME NOVE is an independent accessibility engineering case study built around a fictional European lighting studio. The goal was to prove that a high-end editorial storefront can retain its visual character while making the purchase journey more robust for keyboard and assistive-technology users.

I created the full React and TypeScript experience: storefront filters, product configuration, an accessible modal cart, and a delivery checkout with persistent labels, grouped controls, focus-managed error recovery, and dynamic totals.

To make the remediation measurable, I kept an intentionally inaccessible legacy-checkout fixture outside the production application. axe detects five known violation families in that baseline. The remediated storefront, product page, open cart, checkout, and mobile storefront return zero detected violations under the configured WCAG A/AA rules in the verified build.

The final automated suite passes 6/6 Playwright tests. I also corrected responsive header clipping, protected the full accessible bag name on mobile, removed horizontal overflow at 390px and 1440px, and reduced production imagery from 13.07MB to 615KB.

This is a disclosed self-initiated case study, not a fabricated client project. It demonstrates technical WCAG 2.2 AA-oriented remediation and test evidence; it is not a legal compliance certification.
